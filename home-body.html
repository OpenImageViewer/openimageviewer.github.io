About
Open Image Viewer is a hardware accelerated, light-weight and stand-alone open source image viewer for Windows and Linux.
A prominent guideline of Open Image Viewer is attributed to Human factors and ergonomics by optimizing input (mouse / keyboard) and output (monitor) to the human physiology, thus doing more with less.
The Viewer aims to be the status-quo in viewing and analyzing images with no compromise in performance, comfort or universality. The project is built from scratch using modern techniques, modern libraries and non legacy constraints.
Off-the-shelf supported formats

JPEG (JPG/JPEG/JIF/JPE), PNG/APNG, GIF, WebP, TIFF (TIF/TIFF), Tiff 16 bit float, Tiff 16 bit signed integer, Tiff 24 bit float Tiff 32 bit float, Windows / OS/2 BMP

Photoshop PSD/PSB, DDS, ICO/ICON, CUR

JPEG XR (JXR/WDP/HDP), Kodak Photo CD (PCD), PCX, PGM/PPM in ASCII or binary form, Targa (TGA), Sun Raster (RAS), Amiga IFF/LBM, SGI, Macintosh PICT, Dr. Halo (CUT), X11 Pixmap (XPM)

Wide Camera RAW support (ARW, CR2, CR3, DNG, NEF, ORF, RAF, RW2 and many more) via the bundled LibRaw; compatibility depends on the camera model and encoding
