Open Image Viewer Feature Highlights

Feature Description Tutorial
Fast browsing Read-ahead loading, quick browse (~100 ms per image while holding the mouse navigation buttons), sorting by name / date / extension in ascending or descending order, and slideshows.
Zoom & pan High-precision zoom centered on the cursor and panning that can extend far beyond the edges of the monitor.
Animated images GIF, APNG and WebP animation playback with adjustable speed.
Subimage navigation Step through mipmaps, icon sizes and multi-image files (e.g. multi-page TIFF) with Alt+scroll.
Texel grid & pixel values Toggleable texel grid with two colors for clear visualization in any scenario, per-pixel values and sub-texel position of the mouse cursor.
Accurate image and texel information Precise information about the image: dimensions, color channels and their order, file size and compression ratio, and the texel data as found on disk.
EXIF metadata Embedded EXIF camera metadata, displayed next to the image information.
Hardware color correction Gamma, exposure, offset and saturation are executed on the GPU and can be toggled instantly.
Grayscale / Rainbow normalization Non-destructive normalization of images that cannot be directly converted to RGB (e.g. 16/24/32/64 bit integer and 16/24/32 bit float channels) either to grayscale (black-to-white) or to rainbow colors. Video Tutorial
Multiple transparency modes Four transparency checkerboard visualization modes: light, medium, dark and darker. Helps to clearly visualize transparency for images with different luminosity. Video Tutorial
Optimized selection rectangle High performance, pixel-grid-snapped selection rectangle with a live size label to crop or copy part of the image. Video Tutorial
32 bit clipboard support Copy, cut and paste to/from the clipboard with a transparency channel. It may seem trivial but many renowned applications don't support it.
Quick paste Double right mouse click to paste an image from the clipboard.
Conservative axis aligned transformations Axis aligned transformations such as rotation and flip are resolved according to the initial transformation state while keeping rotation as the primary operation.
For example, flipping an image horizontally and then rotating it 90 degrees clockwise will be resolved and reported to the user as a transformation that is rotated 90 degrees clockwise and flipped vertically.
Save images Save the visible image (with corrections and transformations applied) as JPEG or PNG.
Renderer backends Direct3D 11, Vulkan and OpenGL backends with automatic GPU selection: Windows prefers Direct3D 11, Linux prefers Vulkan.
Keyboard-driven & configurable Every operation is a command. Remap shortcuts in KeyBindings.json and define new commands in Commands.json. Press F1 for the list of active key bindings.
On Screen display File name, notifications and image information are rendered directly into the image area, with no toolbars or dialogs in the way.
Window ergonomics Borderless mode, drag the window from anywhere, resize it from the client area with the Ctrl key, automatic "on top" window, and one-key window sizes (1-5).
Close to tray Press the 'Esc' key to close to tray; the next launch reuses the running instance instead of starting a new one.
Multi-full-screen Allows to span an image across several monitors even with different resolutions. Video Tutorial
Auto reload & file watching Four types of reload mode for files modified outside the viewer (Windows only): don't reload, require user confirmation, load automatically when the application gets active, or load automatically in the background. The working directory follows the file system.
Persistence view Keep image zoom and position unchanged when loading a new file. Useful, for example, when analyzing similar sized images.
Downscaling Improve the quality for large images when zooming out using asynchronous box filtering and cubic downsampling to eliminate aliasing.
Logarithmic Auto Scroll User configurable logarithmic Auto Scroll allows for intuitive, hands-free inspection.
True support for exotic image formats Non destructive and no data loss for unusual formats used by professionals such as 16/24/32/64 bit integer and float 16/24/32 bit channels.
Cross-platform Native 64-bit Windows (7 SP1 and newer) and Linux builds from a single codebase.
Fully open source Open Image Viewer is completely free for non commercial use.
